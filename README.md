# FC26 Career Universe Manager (完成版)

FC26のキャリアモードを超長期的にプレイするための、人間ドラマシミュレーション＆完全事実管理Webアプリケーションです。

---

## 思想とコア原則

1. **ゲーム内事実とシミュレーションの完全分離**
   - 試合結果・スコア・得点者・出場時間・フォーメーション・順位・移籍成立等は**「ユーザーが入力した絶対的事実」**として扱い、アプリ・AI側が改変することはありません。
2. **自動進行の厳格な排除**
   - 怪我、引退、出場停止、勝手な解任、架空選手の加入等は一切自動発生させません。
3. **人間関係・心理の決定論的シミュレーション**
   - 事実（例: 主力選手が10試合中2試合のみ先発）に基づき、「不満の蓄積 → 面談要求 → 代理人からのプレッシャー → 移籍打診」を段階的にシミュレートします。

---

## 1. 起動方法 (ローカル実行)

本アプリはビルド不要の純粋なHTML5/JS (ES6) アプリケーションです。

1. リポジトリをクローンまたはZIP解凍します。
2. `index.html` を各種Webブラウザ（Chrome, Safari, Edge）でダブルクリックして開いてください。

---

## 2. GitHub Pages へのアップロード方法

1. GitHubで新規パブリックリポジトリを作成します (`FC26-Career-Universe-Manager`)。
2. リポジトリのルートに `index.html`, `README.md`, `assets/` ディレクトリをそのままコミット＆プッシュします。
3. リポジトリの **Settings > Pages** へ移動します。
4. **Source** を `Deploy from a branch` に設定し、`main` (または `master`) ブランチの `/ (root)` を選択して **Save** を押します。
5. 発行されたURL (`https://<username>.github.io/FC26-Career-Universe-Manager/`) にアクセスして完了です。

---

## 3. iPhone での利用方法 & ホーム画面追加方法

1. iPhoneの Safari で GitHub Pages のURLを開きます。
2. 画面下部中央の **「共有ボタン」** (四角から矢印が飛び出ているアイコン) をタップします。
3. メニューをスクロールし **「ホーム画面に追加」** を選択します。
4. アイコン名を確認して「追加」をタップすると、Nativeアプリのように全画面かつ高速に起動可能です。

---

## 4. データバックアップ方法

1. ヘッダー右上の **「設定 (歯車アイコン)」** をタップします。
2. **「JSONデータをバックアップ (保存)」** を選択するとローカルに `.json` ファイルがダウンロードされます。
3. 端末変更やブラウザのキャッシュ削除時は、同画面から **「JSONデータ復元」** でいつでも完璧に状態をロードできます。

---

## 5. AI / OCR 機能を接続・拡張する方法 (v2へのロードマップ)

本アプリはAPI非依存の静的動作（ルールベース・モック対応）を標準装備していますが、外部AI API（OpenAI / Gemini等）を接続可能な設計になっています。

* **OCR拡張:** `assets/js/app.js` 内の `handleOCRUpload()` 関数に Tesseract.js または Google Cloud Vision API をバインド可能です。
* **LLM対話拡張:** `app.js` 内の `sendTalkMessage()` 関数から、バックエンド経由またはプロキシ経由でLLM APIへ対話プロンプトを送信するよう改修できます。
